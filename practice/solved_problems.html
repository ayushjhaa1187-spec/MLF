Deep-ML #14: Linear Regression Using Normal Equation
Practice on Deep-ML
Implement linear regression using the closed-form normal equation: $\theta = (X^T X)^{-1} X^T y$. Handle the intercept bias term by augmenting $X$ with a column of ones.
Python Solution: 
import numpy as np

def linear_regression_normal_equation(X: list[list[float]], y: list[float]) -> list[float]:
    X_arr = np.array(X)
    y_arr = np.array(y)
    # Augment with column of ones for intercept
    X_b = np.c_[np.ones((len(X_arr), 1)), X_arr]
    # Normal Equation: theta = (X^T @ X)^-1 @ X^T @ y
    theta = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y_arr
    return np.round(theta, 4).tolist()

Continuity & Removable Singularities
Which of the following functions is continuous at all points in $\mathbb{R}$?
A. $f(x) = \frac{1}{x-1}$
B. $f(x) = \frac{x^2 - 1}{x - 1}$
C. $f(x) = \text{sign}(x - 2)$
D. $f(x) = \sin(x)$
Correct Option: D

Explanation:

• Option B has a removable discontinuity at $x = 1$ because the domain excludes $x = 1$. Even though $\lim_{x \to 1} \frac{x^2-1}{x-1} = 2$, $f(1)$ does not exist.
• Option C has a jump discontinuity at $x = 2$.
• $\sin(x)$ is continuous everywhere on $\mathbb{R}$.

Multivariate Gradient & Tangent Hyperplane
Find the equation of the tangent hyperplane to the surface $f(x_1, x_2) = x_1^2 + 3 x_1 x_2 - x_2^2$ at the point $x_0 = (1, 2)$.
Solution:
1. Value at point: $f(1, 2) = 1^2 + 3(1)(2) - 2^2 = 1 + 6 - 4 = 3$.
2. Partial derivatives:
$$\frac{\partial f}{\partial x_1} = 2 x_1 + 3 x_2 \implies \left.\frac{\partial f}{\partial x_1}\right|_{(1, 2)} = 2(1) + 3(2) = 8$$
$$\frac{\partial f}{\partial x_2} = 3 x_1 - 2 x_2 \implies \left.\frac{\partial f}{\partial x_2}\right|_{(1, 2)} = 3(1) - 2(2) = -1$$
3. Tangent Hyperplane equation: $z = f(x_0) + \nabla f(x_0)^T (x - x_0)$
$$z = 3 + 8(x_1 - 1) - 1(x_2 - 2) = 8 x_1 - x_2 - 3$$

        if x < 2:
            return x
        r = x
        while r * r > x:
            r = (r + x // r) // 2
        return r

    if len(a[0]) != len(b):
        return -1
    result = []
    for row in a:
        dot = sum(row[i] * b[i] for i in range(len(b)))
        result.append(dot)
    return result

Deep-ML #48: Reduced Row Echelon Form (RREF)
Practice on Deep-ML
Implement Gaussian Elimination to compute the Reduced Row Echelon Form (RREF) of a matrix to find basic columns and null space bases.
Python Solution: 
import numpy as np

def rref(matrix: list[list[float]]) -> list[list[float]]:
    A = np.array(matrix, dtype=float)
    rows, cols = A.shape
    r = 0
    for c in range(cols):
        if r >= rows:
            break
        # Find pivot
        pivot = np.argmax(np.abs(A[r:, c])) + r
        if np.isclose(A[pivot, c], 0):
            continue
        # Swap
        A[[r, pivot]] = A[[pivot, r]]
        # Normalize pivot row
        A[r] /= A[r, c]
        # Eliminate column
        for i in range(rows):
            if i != r:
                A[i] -= A[i, c] * A[r]
        r += 1
    return np.round(A, 4).tolist()

Deep-ML #6: Calculate Eigenvalues of a 2x2 Matrix

Given a $2 \times 2$ matrix, return its eigenvalues sorted in descending order by solving the characteristic equation: $\lambda^2 - \text{Tr}(A)\lambda + \det(A) = 0$.
Python Solution: 
def calculate_eigenvalues(matrix: list[list[float]]) -> list[float]:
    a, b = matrix[0][0], matrix[0][1]
    c, d = matrix[1][0], matrix[1][1]
    trace = a + d
    det = a * d - b * c
    discriminant = (trace**2 - 4 * det)**0.5
    lambda1 = (trace + discriminant) / 2
    lambda2 = (trace - discriminant) / 2
    return sorted([round(float(lambda1), 4), round(float(lambda2), 4)], reverse=True)

        if n < 0:
            x = 1 / x
            n = -n

        while n > 0:

                res *= curr

Consider non-zero vectors $x, y \in \mathbb{C}^n$. When does the inner product obey commutative symmetry (i.e. $\langle x, y \rangle = \langle y, x \rangle$)?

Spectral Theorem for 3x3 Symmetric Matrices
Find the eigenvalues of the symmetric matrix $A = \begin{bmatrix} 2 & -1 & 1 \\ -1 & 2 & -1 \\ 1 & -1 & 2 \end{bmatrix}$ using its trace, principal minors, and determinant.
Solution:
1. Trace: $\text{Tr}(A) = 2 + 2 + 2 = 6$.
2. Sum of leading principal minors:
$$M_{11} = \det\begin{bmatrix}2 & -1 \\ -1 & 2\end{bmatrix} = 3, \quad M_{22} = \det\begin{bmatrix}2 & 1 \\ 1 & 2\end{bmatrix} = 3, \quad M_{33} = \det\begin{bmatrix}2 & -1 \\ -1 & 2\end{bmatrix} = 3$$
Sum $= 3 + 3 + 3 = 9$.
3. Determinant: $\det(A) = 2(3) - (-1)(-1) + 1(-1) = 6 - 1 - 1 = 4$.
4. Characteristic equation: $\lambda^3 - 6\lambda^2 + 9\lambda - 4 = 0$.
Factoring: $(\lambda - 1)^2(\lambda - 4) = 0 \implies \lambda = 4, 1, 1$.

Positive Definiteness via Sylvester's Criterion
Let $A = \begin{bmatrix} 4 & 2 \\ 2 & 2 \end{bmatrix}$ and $B = \begin{bmatrix} 1 & 1 \\ 1 & 2 \end{bmatrix}$. Prove whether $A + B$ is positive definite.
Solution:
1. Check $A$: $a = 4 > 0$, $\det(A) = 4(2) - 2^2 = 4 > 0$. Thus $A \succ 0$.
2. Check $B$: $a = 1 > 0$, $\det(B) = 1(2) - 1^2 = 1 > 0$. Thus $B \succ 0$.
3. Matrix sum: $A + B = \begin{bmatrix} 5 & 3 \\ 3 & 4 \end{bmatrix}$.
Leading minor $a = 5 > 0$, determinant $\det(A+B) = 5(4) - 3^2 = 11 > 0$.
Since all leading principal minors are strictly positive, $A + B$ is strictly positive definite.

Deep-ML #12: Singular Value Decomposition (SVD) of 2x2 Matrix
Practice on Deep-ML
Write a function that calculates the Singular Value Decomposition (SVD) of a $2 \times 2$ matrix $A = U \Sigma V^T$ without high-level SVD libraries.
Python Solution: 
import numpy as np

def svd_2x2(A: list[list[float]]):
    A_mat = np.array(A, dtype=float)
    ATA = A_mat.T @ A_mat
    eigvals, V = np.linalg.eigh(ATA)
    idx = np.argsort(eigvals)[::-1]
    eigvals = np.maximum(eigvals[idx], 0.0)
    V = V[:, idx]
    sigma = np.sqrt(eigvals)
    U = np.zeros_like(A_mat)
    for i in range(len(sigma)):
        if sigma[i] > 1e-12:
            U[:, i] = (A_mat @ V[:, i]) / sigma[i]
    return U.tolist(), sigma.tolist(), V.T.tolist()

Deep-ML #19: Principal Component Analysis (PCA) Implementation
Practice on Deep-ML
Implement PCA dimensionality reduction from scratch in Python: center data, compute covariance matrix, compute eigenvectors, and project data to $k$ dimensions.
Python Solution: 
import numpy as np

def pca(data: list[list[float]], k: int) -> list[list[float]]:
    X = np.array(data)
    X_centered = X - np.mean(X, axis=0)
    cov = np.cov(X_centered, rowvar=False)
    eigvals, eigvecs = np.linalg.eigh(cov)
    # Sort descending
    top_indices = np.argsort(eigvals)[::-1][:k]
    components = eigvecs[:, top_indices]
    projected = X_centered @ components
    return np.round(projected, 4).tolist()

Distance Minimization to a Parabola
Find the point(s) on the parabola $y = x^2 + 1$ closest to the point $(0, 2)$.
Solution:
Objective: minimize squared Euclidean distance:
$$f(x) = (x - 0)^2 + (x^2 + 1 - 2)^2 = x^2 + (x^2 - 1)^2 = x^4 - x^2 + 1$$
Derivative: $f'(x) = 4x^3 - 2x = 2x(2x^2 - 1) = 0$.
Critical points: $x = 0$, and $x = \pm \frac{1}{\sqrt{2}} \approx \pm 0.707$.
Second derivative $f''(x) = 12x^2 - 2$:
• At $x = 0$: $f''(0) = -2 < 0$ (local maximum).
• At $x = \pm 0.707$: $f'' = 12(0.5) - 2 = 4 > 0$ (local minima).
Corresponding $y = (\pm 1/\sqrt{2})^2 + 1 = 1.5$.
The closest points are $\mathbf{(0.707, 1.5)}$ and $\mathbf{(-0.707, 1.5)}$.

Deep-ML #15: Linear Regression Using Gradient Descent
Practice on Deep-ML
Implement batch gradient descent for linear regression to iteratively minimize MSE loss over $E$ epochs.
Python Solution: 
import numpy as np

def linear_regression_gradient_descent(X: list[list[float]], y: list[float], lr: float, epochs: int):
    X_mat = np.array(X)
    y_vec = np.array(y)
    m, n = X_mat.shape
    w = np.zeros(n)
    for _ in range(epochs):
        preds = X_mat @ w
        grad = (2 / m) * X_mat.T @ (preds - y_vec)
        w -= lr * grad
    return np.round(w, 4).tolist()

Deep-ML #17: K-Means Clustering
Practice on Deep-ML
Implement the k-Means clustering algorithm using alternating optimization: assign points to nearest centroid, then recompute cluster centroids as means.
Python Solution: 
import numpy as np

def k_means_clustering(points: list[list[float]], k: int, initial_centroids: list[list[float]], max_iterations: int):
    X = np.array(points)
    centroids = np.array(initial_centroids)
    for _ in range(max_iterations):
        dists = np.linalg.norm(X[:, None] - centroids[None, :], axis=2)
        labels = np.argmin(dists, axis=1)
        new_centroids = np.array([X[labels == j].mean(axis=0) if np.any(labels == j) else centroids[j] for j in range(k)])
        if np.allclose(centroids, new_centroids):
            break
        centroids = new_centroids
    return np.round(centroids, 4).tolist()

Implement the Pegasos algorithm for primal Support Vector Machines with mini-batch stochastic subgradient descent.

import numpy as np

def pegasos_svm(X, y, C=1.0, max_iter=100):
    w = np.zeros(X.shape[1])
    for t in range(1, max_iter + 1):
        eta = 1.0 / (C * t)
        for i in range(len(X)):
            if y[i] * np.dot(w, X[i]) < 1:
                w = (1 - eta * C) * w + eta * y[i] * X[i]
            else:
                w = (1 - eta * C) * w
    return w

LeetCode 528: Random Pick with Weight

Given an array of positive integers `w` representing probabilities, pick an index randomly proportional to its weight using cumulative distribution function (CDF) sampling.
Python Solution: 
import random
import bisect

class Solution:
    def __init__(self, w: list[int]):
        self.prefix_sums = []
        curr = 0
        for weight in w:
            curr += weight
            self.prefix_sums.append(curr)
        self.total = curr

    def pickIndex(self) -> int:
        target = random.randint(1, self.total)
        return bisect.bisect_left(self.prefix_sums, target)
IITM BS Exam Week 12 Hard
Maximum Likelihood for Gaussian Parameters
Given independent 1D observations $\{x_1, x_2, \dots, x_N\} \sim \mathcal{N}(\mu, \sigma^2)$, derive the Maximum Likelihood Estimator (MLE) for mean $\mu$ and variance $\sigma^2$ and state whether the variance estimator is biased.
Solution:
Log-likelihood:
$$\ln L(\mu, \sigma^2) = -\frac{N}{2}\ln(2\pi) - \frac{N}{2}\ln(\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^N (x_i - \mu)^2$$
1. $\frac{\partial \ln L}{\partial \mu} = \frac{1}{\sigma^2}\sum_{i=1}^N (x_i - \mu) = 0 \implies \hat{\mu}_{MLE} = \frac{1}{N}\sum_{i=1}^N x_i$. (Unbiased)
2. $\frac{\partial \ln L}{\partial (\sigma^2)} = -\frac{N}{2\sigma^2} + \frac{1}{2(\sigma^2)^2}\sum_{i=1}^N (x_i - \mu)^2 = 0 \implies \hat{\sigma}^2_{MLE} = \frac{1}{N}\sum_{i=1}^N (x_i - \hat{\mu})^2$.
Bias: $\mathbb{E}[\hat{\sigma}^2_{MLE}] = \frac{N-1}{N} \sigma^2 \neq \sigma^2$, so the MLE variance is biased by factor $\frac{N-1}{N}$.

Deep-ML #23: Softmax Activation Function Implementation
Practice on Deep-ML
Implement the numerically stable Softmax activation function: $\text{Softmax}(z)_i = \frac{e^{z_i - \max(z)}}{\sum_j e^{z_j - \max(z)}}$.

import numpy as np

def softmax(scores: list[float]) -> list[float]:
