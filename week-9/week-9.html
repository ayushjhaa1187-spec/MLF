Week 9: Constrained Optimization, Lagrange Multipliers & Convexity

Detailed notes, algorithmic foundations, mathematical formulations, and Python implementations aligned with the IIT Madras lecture series.

1. Constrained Optimization & Lagrange Multipliers

When parameters are restricted to a feasible domain, we formulate constrained optimization:

$$\min_{x} f(x) \quad \text{subject to} \quad h_i(x) = 0, \; i = 1, \dots, m$$

At an optimal point $x^*$, the objective gradient $\nabla f(x^*)$ must lie in the subspace orthogonal to the constraint surface. Thus, it can be written as a linear combination of constraint gradients:

$$\nabla f(x^*) + \sum_{i=1}^m \lambda_i \nabla h_i(x^*) = 0$$

This justifies the Lagrangian Function:

$$\mathcal{L}(x, \lambda) = f(x) + \sum_{i=1}^m \lambda_i h_i(x)$$

Stationary conditions $\nabla_x \mathcal{L} = 0$ and $\nabla_\lambda \mathcal{L} = 0$ recover both feasibility and optimality simultaneously.

2. Convex Sets & Convex Functions

Convex Set

A set $C \subseteq \mathbb{R}^d$ is convex if the line segment connecting any two points in $C$ lies entirely within $C$: $$\forall x, y \in C, \; \theta \in [0, 1] \implies \theta x + (1 - \theta) y \in C$$

Convex Function

A function $f: C \to \mathbb{R}$ is convex if the chord connecting $(x, f(x))$ and $(y, f(y))$ lies above the function graph (Jensen's inequality): $$f(\theta x + (1-\theta)y) \le \theta f(x) + (1-\theta)f(y)$$

Global Optimality Property

For a convex objective function over a convex set, every local minimum is guaranteed to be a global minimum!

3. Projected Gradient Descent

To optimize $f(x)$ over a convex constraint set $\mathcal{C}$, Projected Gradient Descent interleaves standard gradient steps with Euclidean projection onto $\mathcal{C}$:

$$x_{t+1} = \Pi_{\mathcal{C}} (x_t - \eta \nabla f(x_t))$$

where $\Pi_{\mathcal{C}}(y) = \arg\min_{z \in \mathcal{C}} \|z - y\|_2$. For an $\ell_2$ ball $\mathcal{C} = \{z : \|z\|_2 \le R\}$, the projection is simple vector clipping: $\Pi_{\mathcal{C}}(y) = y \cdot \min(1, R/\|y\|_2)$.

4. Python Implementation: Projected Gradient Descent

import numpy as np

# Minimize f(x, y) = (x - 3)^2 + (y - 4)^2 subject to ||(x, y)||_2 <= 2
def grad_f(w):
    return 2 * (w - np.array([3.0, 4.0]))

def project_l2_ball(w, radius=2.0):
    norm = np.linalg.norm(w)
    if norm > radius:
        return (radius / norm) * w
    return w

w = np.array([0.0, 0.0])
lr = 0.1

for step in range(100):
    # 1. Gradient step
    w_unconstrained = w - lr * grad_f(w)
    # 2. Projection step
    w = project_l2_ball(w_unconstrained, radius=2.0)

print("Optimized point on constraint boundary:", w)
print("Norm of solution (should be exactly 2.0):", np.linalg.norm(w))
# Analytical solution points in direction of target (3, 4): 2 * [3/5, 4/5] = [1.2, 1.6]
print("Analytical optimum:", np.array([1.2, 1.6]))
