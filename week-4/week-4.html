Week 4: Regression, Eigenvalues & Matrix Diagonalization

Detailed notes, algorithmic foundations, mathematical formulations, and Python implementations aligned with the IIT Madras lecture series.

1. Linear & Polynomial Regression via Feature Maps

Polynomial regression fits non-linear relationships by mapping input $x \in \mathbb{R}$ into a higher-dimensional polynomial basis $\phi(x) = [1, x, x^2, \dots, x^d]^T$. The problem remains mathematically linear with respect to the parameter vector $w$:

$$f_w(x) = w^T \phi(x) = w_0 + w_1 x + w_2 x^2 + \dots + w_d x^d$$

Constructing the Vandermonde design matrix $\Phi \in \mathbb{R}^{N \times (d+1)}$ reduces polynomial fitting back to ordinary least squares: $w^* = (\Phi^T \Phi)^{-1} \Phi^T y$.

2. Eigenvalues & Eigenvectors: Geometric Intuition

For a square matrix $A \in \mathbb{R}^{n \times n}$, an eigenvector $v \neq 0$ is a special vector whose direction is unchanged by matrix multiplication, merely scaled by an eigenvalue $\lambda$:

$$Av = \lambda v \iff (A - \lambda I)v = 0$$

Non-trivial solutions require the characteristic equation: $\det(A - \lambda I) = 0$.

Geometric Meaning

A matrix $A$ acts on space by rotating, reflecting, and stretching vectors. Eigenvectors are the invariant axes of this transformation, and the eigenvalues $\lambda$ are the stretch factors along those axes.

3. Matrix Diagonalization & Powers ($A^k$)

If $A$ has $n$ linearly independent eigenvectors $v_1, \dots, v_n$, we form modal matrix $P = [v_1 | v_2 | \dots | v_n]$ and diagonal matrix $\Lambda = \text{diag}(\lambda_1, \dots, \lambda_n)$:

$$AP = P\Lambda \implies A = P \Lambda P^{-1}$$

Computing matrix powers simplifies to: $A^k = P \Lambda^k P^{-1}$, which enables closed-form solutions to linear dynamical systems and Fibonacci numbers.

4. Python Implementation: Polynomial Fit & Eigendecomposition

import numpy as np

# 1. Polynomial feature fitting
x_data = np.linspace(-2, 2, 20)
y_data = 1.5 * x_data**2 - 2.0 * x_data + 0.5 + np.random.randn(20)*0.2

# Vandermonde matrix for degree 2: [1, x, x^2]
Phi = np.column_stack([np.ones_like(x_data), x_data, x_data**2])
weights = np.linalg.inv(Phi.T @ Phi) @ Phi.T @ y_data
print("Fitted weights [w0, w1, w2]:", weights)

# 2. Eigendecomposition of a 2x2 matrix
M = np.array([[4, 1], [2, 3]])
eigenvalues, eigenvectors = np.linalg.eig(M)
print("Eigenvalues:", eigenvalues)
print("Eigenvectors:\n", eigenvectors)

# Verify A = P @ Lambda @ P^-1
P = eigenvectors
Lambda = np.diag(eigenvalues)
M_reconstructed = P @ Lambda @ np.linalg.inv(P)
print("Reconstruction matches M:", np.allclose(M, M_reconstructed))
