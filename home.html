The Four Pillars of Machine Learning

This course bridges theoretical mathematics with machine learning practice across four foundational pillars:

1. Linear Algebra

Subspaces, Orthogonal Projections, Gram-Schmidt, Eigenvalues, SVD, Positive Definiteness, and Matrix Factorization for dimensional representation.

2. Optimization & Calculus

Multivariate gradients, Hessian curvature, Taylor expansions, Convexity, Method of Lagrange Multipliers, and KKT Duality theorems.

3. Probability & Stats

Joint and conditional distributions, Expectations, Covariance, Multivariate Gaussians, Maximum Likelihood (MLE), and Laws of Large Numbers.

4. Learning Algorithms

Least Squares Regression, Polynomial fitting, PCA variance maximization, Support Vector Machines, GMMs, and Expectation-Maximization (EM).

How to Use this Textbook Effectively

1. Watch & Read Concurrently: Each weekly chapter contains embedded video players with direct lecture markers matching the IIT Madras playlist.

2. Run the Code Locally: Every algorithm is provided as runnable Python / NumPy code. You can copy and execute the snippets in Jupyter notebooks or Google Colab.

3. Exam & Interview Preparation: Review the Summary page at the end of each week for mathematical definitions, theorem statements, and complexity metrics.
