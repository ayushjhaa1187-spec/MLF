Week 12: Multivariate Gaussians, GMMs, EM Algorithm & Limit Theorems

Detailed notes, algorithmic foundations, mathematical formulations, and Python implementations aligned with the IIT Madras lecture series.

1. Multivariate Normal Distribution & Parameter Estimation

A random vector $X \in \mathbb{R}^d$ follows a Multivariate Normal distribution $\mathcal{N}(\mu, \Sigma)$ with mean $\mu \in \mathbb{R}^d$ and positive definite covariance $\Sigma \in \mathbb{R}^{d \times d}$:

$$f_X(x) = \frac{1}{(2\pi)^{d/2} |\Sigma|^{1/2}} \exp\left( -\frac{1}{2} (x - \mu)^T \Sigma^{-1} (x - \mu) \right)$$

Maximum Likelihood Estimation (MLE): Given i.i.d. observations $\{x_1, \dots, x_N\}$, the log-likelihood is:

$$\ln L(\mu, \Sigma) = -\frac{Nd}{2}\ln(2\pi) - \frac{N}{2}\ln|\Sigma| - \frac{1}{2} \sum_{i=1}^N (x_i - \mu)^T \Sigma^{-1} (x_i - \mu)$$

Maximizing yields the analytical MLE estimates: $\hat{\mu}_{MLE} = \frac{1}{N}\sum x_i$, and $\hat{\Sigma}_{MLE} = \frac{1}{N}\sum (x_i - \hat{\mu})(x_i - \hat{\mu})^T$.

2. Gaussian Mixture Models (GMM) & The EM Algorithm

When data originates from multiple sub-populations, a single Gaussian is inadequate. A Gaussian Mixture Model expresses density as a convex combination of $K$ Gaussians:

$$p(x) = \sum_{k=1}^K \pi_k \mathcal{N}(x | \mu_k, \Sigma_k), \quad \sum_{k=1}^K \pi_k = 1, \; \pi_k \ge 0$$

Because cluster assignments $z_i \in \{1, \dots, K\}$ are unobserved latent variables, direct MLE has no closed form. We apply the Expectation-Maximization (EM) algorithm:

E-Step (Expectation)

Compute posterior responsibility of cluster $k$ for point $x_i$: $$\gamma_{ik} = \frac{\pi_k \mathcal{N}(x_i | \mu_k, \Sigma_k)}{\sum_{j=1}^K \pi_j \mathcal{N}(x_i | \mu_j, \Sigma_j)}$$

M-Step (Maximization)

Re-estimate parameters using weighted sums: $$N_k = \sum_{i=1}^N \gamma_{ik}, \quad \mu_k = \frac{1}{N_k} \sum_{i=1}^N \gamma_{ik} x_i$$ $$\Sigma_k = \frac{1}{N_k} \sum_{i=1}^N \gamma_{ik} (x_i - \mu_k)(x_i - \mu_k)^T$$

3. Laws of Large Numbers & Concentration Inequalities

How fast does empirical performance converge to theoretical expectation? Key concentration bounds provide rigorous guarantees:

  • Markov's Inequality: For non-negative $X \ge 0$ and $a > 0$: $P(X \ge a) \le \frac{\mathbb{E}[X]}{a}$.
  • Chebyshev's Inequality: $P(|X - \mu| \ge k\sigma) \le \frac{1}{k^2}$.
  • Central Limit Theorem (CLT): For i.i.d. variables with mean $\mu$ and variance $\sigma^2$, the standardized sample mean converges in distribution to standard normal: $$\sqrt{N} \left( \frac{\bar{X}_N - \mu}{\sigma} \right) \xrightarrow{d} \mathcal{N}(0, 1)$$

4. Python Implementation: Gaussian Mixture Model & EM

import numpy as np

# EM Algorithm for 1D GMM (2 components)
np.random.seed(42)
data = np.concatenate([np.random.normal(2.0, 1.0, 300), np.random.normal(8.0, 1.5, 300)])

def gaussian_pdf(x, mu, sigma):
    return (1.0 / (np.sqrt(2 * np.pi) * sigma)) * np.exp(-0.5 * ((x - mu) / sigma)**2)

# Initial parameters
mu1, mu2 = 0.0, 5.0
s1, s2 = 1.0, 1.0
pi1, pi2 = 0.5, 0.5

for iteration in range(25):
    # E-step
    pdf1 = pi1 * gaussian_pdf(data, mu1, s1)
    pdf2 = pi2 * gaussian_pdf(data, mu2, s2)
    gamma1 = pdf1 / (pdf1 + pdf2)
    gamma2 = pdf2 / (pdf1 + pdf2)

    # M-step
    N1 = np.sum(gamma1)
    N2 = np.sum(gamma2)

    mu1 = np.sum(gamma1 * data) / N1
    mu2 = np.sum(gamma2 * data) / N2

    s1 = np.sqrt(np.sum(gamma1 * (data - mu1)**2) / N1)
    s2 = np.sqrt(np.sum(gamma2 * (data - mu2)**2) / N2)

    pi1 = N1 / len(data)
    pi2 = N2 / len(data)

print(f"Estimated Component 1: Mean = {mu1:.2f}, Std = {s1:.2f}")
print(f"Estimated Component 2: Mean = {mu2:.2f}, Std = {s2:.2f}")
