Rank-Nullity Theorem: $\text{rank}(A) + \text{nullity}(A) = n$  |  $\mathbb{R}^n = C(A^T) \oplus N(A)$  |  $\mathbb{R}^m = C(A) \oplus N(A^T)$

2. Projection Operators & Matrices

Projection onto a 1D Line (Span of $v$)
$$p = \frac{v^T b}{v^T v} v, \quad P = \frac{v v^T}{v^T v}$$

Numerator is outer product (matrix); denominator is inner product (scalar).

Projection onto Subspace $C(A)$
$$p = A(A^T A)^{-1} A^T b, \quad P = A(A^T A)^{-1} A^T$$

Requires linearly independent columns in $A$ ($\text{rank}(A) = n$).

Key Algebraic Properties of any Orthogonal Projection Matrix $P$:
  • Symmetry: $P^T = P$
  • Idempotency: $P^2 = P$
  • Eigenvalues: $\lambda \in \{0, 1\}$ (multiplicity of 1 is rank $r$; multiplicity of 0 is $m - r$)
  • Complementary Projection: $I - P$ projects orthogonally onto $N(A^T)$

3. Least Squares Formulation

The Normal Equations
$$A^T A \hat{x} = A^T b \implies \hat{x} = (A^T A)^{-1} A^T b$$

Orthogonality Principle: $A^T e = A^T (b - A\hat{x}) = 0 \iff e \perp C(A)$.

Residual Sum of Squares (RSS): $$\|e\|_2^2 = \|b - A\hat{x}\|_2^2 = b^T b - \hat{x}^T A^T b$$
Pythagorean Decomposition: $$\|b\|_2^2 = \|p\|_2^2 + \|e\|_2^2$$

4. Essential NumPy Syntax

import numpy as np

# 1. Least Squares via Normal Equations
x_hat = np.linalg.solve(A.T @ A, A.T @ b)

# 2. Recommended Production QR Solver
Q, R = np.linalg.qr(A, mode='reduced')
x_hat_qr = np.linalg.solve(R, Q.T @ b)

# 3. Built-in SVD Solver
x_hat_lstsq, residuals, rank, s = np.linalg.lstsq(A, b, rcond=None)

# 4. Projection Matrix & Residuals
P = A @ np.linalg.inv(A.T @ A) @ A.T
p = P @ b
e = b - p
