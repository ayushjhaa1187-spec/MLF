Week 3: High-Yield Summary

Linear Algebra: Subspaces, Orthogonality & Least Squares • Core Formulas, Definitions & Quick Code

Fundamental Theorem
$\text{Row}(A) \oplus \text{Null}(A) = \mathbb{R}^n$, $\text{Col}(A) \oplus \text{Null}(A^T) = \mathbb{R}^m$.
Normal Equations
$A^T A \hat{x} = A^T b \implies \hat{x} = (A^T A)^{-1} A^T b$.
Projection Matrix
$P = A(A^T A)^{-1} A^T$. Satisfies $P^T = P$ and $P^2 = P$.
