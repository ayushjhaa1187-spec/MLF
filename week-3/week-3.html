Week 3: Linear Algebra: Subspaces, Orthogonality & Least Squares

Detailed notes, algorithmic foundations, mathematical formulations, and Python implementations aligned with the IIT Madras lecture series.

1. The Four Fundamental Subspaces of a Matrix

For any real matrix $A \in \mathbb{R}^{m \times n}$, Gilbert Strang's Fundamental Theorem of Linear Algebra reveals four interconnected subspaces:

SubspaceNotationResides inDimension
Column Space$\text{Col}(A)$$\mathbb{R}^m$$r$ (rank)
Row Space$\text{Row}(A) = \text{Col}(A^T)$$\mathbb{R}^n$$r$
Null Space$\text{Null}(A)$$\mathbb{R}^n$$n - r$
Left Null Space$\text{Null}(A^T)$$\mathbb{R}^m$$m - r$
Orthogonal Complements

$$\text{Row}(A) \perp \text{Null}(A) \implies \mathbb{R}^n = \text{Row}(A) \oplus \text{Null}(A)$$

$$\text{Col}(A) \perp \text{Null}(A^T) \implies \mathbb{R}^m = \text{Col}(A) \oplus \text{Null}(A^T)$$

2. Orthogonal Projections & Projection Matrix

Let $S = \text{Col}(A)$ be a subspace of $\mathbb{R}^m$ spanned by linearly independent columns of $A$. To project an arbitrary vector $b \in \mathbb{R}^m$ onto $S$, we seek a vector $p = A\hat{x} \in S$ such that the error vector $e = b - p$ is orthogonal to every column of $A$:

$$A^T (b - A\hat{x}) = 0 \implies A^T A \hat{x} = A^T b$$

Since the columns of $A$ are linearly independent, $A^TA$ is invertible, yielding the least squares coefficient:

$$\hat{x} = (A^T A)^{-1} A^T b$$

The projection vector $p$ is therefore $p = A\hat{x} = A(A^T A)^{-1} A^T b$. Thus, the Projection Matrix is:

$$P = A(A^T A)^{-1} A^T$$

Properties of $P$: Symmetric ($P^T = P$) and Idempotent ($P^2 = P$).

3. The Method of Least Squares

When solving an overdetermined system $Ax = b$ ($m > n$, more equations than unknowns), an exact solution rarely exists. Least Squares finds the vector $\hat{x}$ minimizing the Euclidean norm of residuals:

$$\min_x \|Ax - b\|_2^2 = \min_x (Ax - b)^T (Ax - b)$$

Setting the gradient to zero yields the exact same Normal Equations:

$$\nabla_x [x^T A^T A x - 2 b^T A x + b^T b] = 2 A^T A x - 2 A^T b = 0 \implies A^T A \hat{x} = A^T b$$

4. Python Implementation: Least Squares & Projection

import numpy as np

# Overdetermined system Ax = b
A = np.array([
    [1, 1],
    [1, 2],
    [1, 3],
    [1, 4]
])
b = np.array([2.1, 3.9, 6.2, 7.8])

# 1. Normal Equations: (A^T A) x = A^T b
ATA = A.T @ A
ATb = A.T @ b
x_hat = np.linalg.solve(ATA, ATb)
print("Least Squares Solution (Slope & Intercept):", x_hat)

# 2. Projection Matrix P = A (A^T A)^-1 A^T
P = A @ np.linalg.inv(ATA) @ A.T
p = P @ b
print("Projected vector p in Col(A):", p)
print("Residual error e = b - p:", b - p)
print("Orthogonality check A^T @ e (should be ~0):", np.round(A.T @ (b - p), 5))
