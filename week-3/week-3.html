1. Module Overview & Learning Objectives

In physical modeling, data science, and machine learning, we routinely collect more empirical observations ($m$) than parameters ($n$). This produces an overdetermined linear system $Ax = b$ where no exact solution exists because the measurement vector $b$ does not lie precisely in the subspace spanned by the feature columns of $A$.

Core Learning Objectives
  • Master the Four Fundamental Subspaces: Define Column Space $C(A)$, Row Space $C(A^T)$, Null Space $N(A)$, and Left Null Space $N(A^T)$, articulating their dimensions and orthogonal complement relationships.
  • Derive the Orthogonality Principle: Prove why the residual error vector $e = b - p$ must be perpendicular to $C(A)$ to minimize Euclidean distance.
  • Construct Projection Matrices: Formulate rank-1 projection matrices $P = rac{v v^T}{v^T v}$ and general subspace projection matrices $P = A(A^T A)^{-1} A^T$, verifying algebraic symmetry ($P^T = P$) and idempotency ($P^2 = P$).
  • Solve Normal Equations: Compute the least squares parameter vector $\hat{x} = (A^T A)^{-1} A^T b$ and evaluate the residual sum of squares $\|e\|_2^2$.
  • Understand Numerical Realities: Distinguish between normal equations, QR factorization ($A = QR$), and Singular Value Decomposition (SVD) in the presence of ill-conditioned data.

2. Big Picture & Geometric Intuition

Consider an experiment recording house sizes and prices. If we collect 1,000 houses with 2 features, our design matrix $A$ has shape $1000 imes 2$. The column space $C(A)$ is merely a 2-dimensional plane slicing through a 1,000-dimensional universe $\mathbb{R}^{1000}$.

Our observation vector $b \in \mathbb{R}^{1000}$ almost never lands directly on this 2D plane due to noise, unobserved variables, and random measurement perturbations. The fundamental question of Machine Learning is:

"What is the single point on the plane $C(A)$ that lies closest to our observed vector $b$?"

The answer is the orthogonal projection $p = A\hat{x}$. By dropping a perpendicular shadow from $b$ onto the subspace, the line segment connecting $b$ to $p$—the error vector $e = b - p$—is as short as mathematically possible.

3. Conceptual Derivations

3.1 The Four Fundamental Subspaces (Gilbert Strang's Theorem)

Let $A \in \mathbb{R}^{m imes n}$ with rank $r = ext{rank}(A) \le \min(m, n)$. Associated with $A$ are four canonical vector subspaces:

Subspace Definition Ambient Space Dimension Orthogonal Complement
Column Space $C(A)$ $\{Ax \mid x \in \mathbb{R}^n\}$ $\mathbb{R}^m$ $r$ $N(A^T)$ (Left Null Space)
Null Space $N(A)$ $\{x \in \mathbb{R}^n \mid Ax = 0\}$ $\mathbb{R}^n$ $n - r$ $C(A^T)$ (Row Space)
Row Space $C(A^T)$ $\{A^T y \mid y \in \mathbb{R}^m\}$ $\mathbb{R}^n$ $r$ $N(A)$ (Null Space)
Left Null Space $N(A^T)$ $\{y \in \mathbb{R}^m \mid A^T y = 0\}$ $\mathbb{R}^m$ $m - r$ $C(A)$ (Column Space)
The Fundamental Decomposition Theorem
$$\mathbb{R}^n = C(A^T) \oplus N(A) \quad ext{and} \quad \mathbb{R}^m = C(A) \oplus N(A^T)$$

Every vector in $\mathbb{R}^n$ uniquely decomposes into a row space component and a null space component. Every vector in $\mathbb{R}^m$ uniquely decomposes into a column space component and a left null space component.

3.2 The Orthogonality Principle

We seek $x \in \mathbb{R}^n$ to minimize the squared Euclidean loss function:

$$J(x) = \|Ax - b\|_2^2 = (Ax - b)^T (Ax - b) = x^T A^T A x - 2 b^T A x + b^T b$$

Taking the matrix gradient with respect to $x$ and setting it to zero:

$$ abla_x J(x) = 2 A^T A x - 2 A^T b = 0 \implies A^T (Ax - b) = 0$$

Defining the residual error vector $e = b - A\hat{x}$, this condition states:

$$A^T e = 0 \iff egin{bmatrix} a_1^T \ a_2^T \ dots \ a_n^T \end{bmatrix} e = egin{bmatrix} 0 \ 0 \ dots \ 0 \end{bmatrix}$$

This is the famous Orthogonality Principle: the residual error vector $e$ is simultaneously orthogonal to every column vector $a_i$ of matrix $A$, which implies $e \perp C(A)$ and therefore $e \in N(A^T)$.

3.3 Invertibility of $A^T A$

To solve $A^T A \hat{x} = A^T b$, when is $A^T A$ guaranteed to be invertible?

Theorem: Full Column Rank Invertibility

$A^T A \in \mathbb{R}^{n imes n}$ is invertible if and only if the columns of $A$ are linearly independent ($ ext{rank}(A) = n$).

Proof: Suppose $A^T A x = 0$. Multiply on the left by $x^T$: $x^T A^T A x = (Ax)^T (Ax) = \|Ax\|_2^2 = 0$. Because the Euclidean norm is positive definite, $\|Ax\|_2 = 0 \implies Ax = 0$. If $A$ has linearly independent columns, its null space contains only the zero vector: $N(A) = \{0\}$. Hence $x = 0$, proving $N(A^T A) = \{0\}$, so $A^T A$ is non-singular and invertible. $lacksquare$

3.4 The Projection Matrix $P$

With $A^T A$ invertible, the unique least squares parameter solution is:

$$\hat{x} = (A^T A)^{-1} A^T b$$

The projected vector $p \in C(A)$ is obtained by evaluating $A\hat{x}$:

$$p = A\hat{x} = A(A^T A)^{-1} A^T b = P b$$

where the Subspace Projection Matrix is:

$$P = A(A^T A)^{-1} A^T$$
Symmetry Property
$$P^T = \left( A(A^T A)^{-1} A^T ight)^T = (A^T)^T \left( (A^T A)^{-1} ight)^T A^T = A(A^T A)^{-1} A^T = P$$
Idempotent Property
$$P^2 = P P = A(A^T A)^{-1} A^T A (A^T A)^{-1} A^T = A I (A^T A)^{-1} A^T = P$$

4. Step-by-Step Worked Numerical Walkthroughs

Worked Example 1: Full 2D Linear Regression via Normal Equations

Problem Statement: Fit a line $y = heta_1 x + heta_2$ through three observational data points: $(1, 2)$, $(2, 2)$, and $(3, 4)$.

Step 1: Set up the matrix system $A heta = b$
$$egin{bmatrix} 1 & 1 \ 2 & 1 \ 3 & 1 \end{bmatrix} egin{bmatrix} heta_1 \ heta_2 \end{bmatrix} = egin{bmatrix} 2 \ 2 \ 4 \end{bmatrix}, \quad ext{where } A \in \mathbb{R}^{3 imes 2}, \; b \in \mathbb{R}^3$$
Step 2: Compute $A^T A$
$$A^T A = egin{bmatrix} 1 & 2 & 3 \ 1 & 1 & 1 \end{bmatrix} egin{bmatrix} 1 & 1 \ 2 & 1 \ 3 & 1 \end{bmatrix} = egin{bmatrix} 1^2 + 2^2 + 3^2 & 1(1) + 2(1) + 3(1) \ 1(1) + 1(2) + 1(3) & 1^2 + 1^2 + 1^2 \end{bmatrix} = egin{bmatrix} 14 & 6 \ 6 & 3 \end{bmatrix}$$
Step 3: Invert $A^T A$ analytically
$$\det(A^T A) = (14)(3) - (6)(6) = 42 - 36 = 6$$ $$(A^T A)^{-1} = rac{1}{6} egin{bmatrix} 3 & -6 \ -6 & 14 \end{bmatrix} = egin{bmatrix} 1/2 & -1 \ -1 & 7/3 \end{bmatrix}$$
Step 4: Compute $A^T b$
$$A^T b = egin{bmatrix} 1 & 2 & 3 \ 1 & 1 & 1 \end{bmatrix} egin{bmatrix} 2 \ 2 \ 4 \end{bmatrix} = egin{bmatrix} 1(2) + 2(2) + 3(4) \ 2 + 2 + 4 \end{bmatrix} = egin{bmatrix} 2 + 4 + 12 \ 8 \end{bmatrix} = egin{bmatrix} 18 \ 8 \end{bmatrix}$$
Step 5: Solve for parameter vector $\hat{ heta}$
$$\hat{ heta} = (A^T A)^{-1} A^T b = egin{bmatrix} 1/2 & -1 \ -1 & 7/3 \end{bmatrix} egin{bmatrix} 18 \ 8 \end{bmatrix} = egin{bmatrix} (1/2)(18) - 1(8) \ -1(18) + (7/3)(8) \end{bmatrix} = egin{bmatrix} 9 - 8 \ -18 + 56/3 \end{bmatrix} = egin{bmatrix} 1 \ 2/3 \end{bmatrix}$$

The fitted least squares regression line is: $y = 1 \cdot x + rac{2}{3}$.

Step 6: Compute predicted vector $p$, error $e$, and verify orthogonality
$$p = A\hat{ heta} = egin{bmatrix} 1 & 1 \ 2 & 1 \ 3 & 1 \end{bmatrix} egin{bmatrix} 1 \ 2/3 \end{bmatrix} = egin{bmatrix} 1 + 2/3 \ 2 + 2/3 \ 3 + 2/3 \end{bmatrix} = egin{bmatrix} 5/3 \ 8/3 \ 11/3 \end{bmatrix}$$ $$e = b - p = egin{bmatrix} 2 \ 2 \ 4 \end{bmatrix} - egin{bmatrix} 5/3 \ 8/3 \ 11/3 \end{bmatrix} = egin{bmatrix} 1/3 \ -2/3 \ 1/3 \end{bmatrix}$$

Verify $A^T e = 0$:

$$A^T e = egin{bmatrix} 1 & 2 & 3 \ 1 & 1 & 1 \end{bmatrix} egin{bmatrix} 1/3 \ -2/3 \ 1/3 \end{bmatrix} = egin{bmatrix} 1(1/3) + 2(-2/3) + 3(1/3) \ 1/3 - 2/3 + 1/3 \end{bmatrix} = egin{bmatrix} 1/3 - 4/3 + 3/3 \ 0 \end{bmatrix} = egin{bmatrix} 0 \ 0 \end{bmatrix} \quad \checkmark$$

Residual Sum of Squares (RSS):

$$\|e\|_2^2 = (1/3)^2 + (-2/3)^2 + (1/3)^2 = rac{1 + 4 + 1}{9} = rac{6}{9} = rac{2}{3} pprox 0.6667$$
Worked Example 2: Orthogonal Projection onto a 2D Plane in $\mathbb{R}^3$

Problem Statement: Find the orthogonal projection of vector $b = egin{bmatrix} 1 \ 2 \ 3 \end{bmatrix}$ onto the 2D subspace plane defined by $x_1 - x_2 + 2x_3 = 0$.

Method: Projection via the Normal Vector to the Plane

The plane passes through the origin with normal vector $n = egin{bmatrix} 1 \ -1 \ 2 \end{bmatrix}$. Any vector $b$ decomposes into:

$$b = p_{ ext{plane}} + p_{ ext{normal}}$$

The 1D projection onto line $n$ is given by:

$$p_{ ext{normal}} = rac{n^T b}{n^T n} n$$ $$n^T b = 1(1) + (-1)(2) + 2(3) = 1 - 2 + 6 = 5$$ $$n^T n = 1^2 + (-1)^2 + 2^2 = 1 + 1 + 4 = 6$$ $$p_{ ext{normal}} = rac{5}{6} egin{bmatrix} 1 \ -1 \ 2 \end{bmatrix} = egin{bmatrix} 5/6 \ -5/6 \ 5/3 \end{bmatrix}$$
Subtract to find projection onto the plane:
$$p_{ ext{plane}} = b - p_{ ext{normal}} = egin{bmatrix} 1 \ 2 \ 3 \end{bmatrix} - egin{bmatrix} 5/6 \ -5/6 \ 10/6 \end{bmatrix} = egin{bmatrix} 1/6 \ 17/6 \ 8/6 \end{bmatrix} = egin{bmatrix} 1/6 \ 17/6 \ 4/3 \end{bmatrix}$$
Verification:

Check if $p_{ ext{plane}}$ satisfies the plane equation $x_1 - x_2 + 2x_3 = 0$:

$$ rac{1}{6} - rac{17}{6} + 2\left( rac{8}{6} ight) = rac{1 - 17 + 16}{6} = rac{0}{6} = 0 \quad \checkmark$$

6. Edge Cases, Pitfalls & Failure Modes

Multicollinearity & Rank Deficiency

If feature columns in $A$ are linearly dependent, $ ext{rank}(A) < n$.

Impact: $\det(A^T A) = 0$. $A^T A$ has no inverse. Infinitely many parameter vectors $\hat{x}$ minimize $\|Ax - b\|_2^2$. In software, `np.linalg.inv(X.T @ X)` crashes with a `LinAlgError: Singular matrix`.

Condition Number Squaring

The condition number $\kappa(A) = \sigma_{\max} / \sigma_{\min}$ quantifies sensitivity to numerical errors.

Catastrophic Flaw: Forming $A^T A$ explicitly squares the condition number: $\kappa(A^T A) = \kappa(A)^2$. If $\kappa(A) = 10^8$, $\kappa(A^T A) = 10^{16}$, completely destroying 64-bit IEEE floating-point precision!

7. Algorithmic Formulation: QR Factorization vs. Normal Equations

Because solving $(A^T A)\hat{x} = A^T b$ directly can be numerically unstable, production machine learning libraries (such as NumPy, SciPy, and LAPACK) utilize QR Decomposition.

The QR Algorithm
  1. Factorize $A \in \mathbb{R}^{m imes n}$ ($m \ge n$) into $A = Q R$, where $Q \in \mathbb{R}^{m imes n}$ has orthonormal columns ($Q^T Q = I_n$) and $R \in \mathbb{R}^{n imes n}$ is upper triangular.
  2. Substitute $A = Q R$ into the normal equations: $$(QR)^T (QR) \hat{x} = (QR)^T b \implies R^T (Q^T Q) R \hat{x} = R^T Q^T b$$ $$R^T R \hat{x} = R^T (Q^T b)$$
  3. Multiply both sides by $(R^T)^{-1}$ (since $R$ is invertible for full-rank $A$): $$R \hat{x} = Q^T b$$
  4. Solve $R \hat{x} = Q^T b$ instantly via back-substitution in $O(n^2)$ flops without inverting any matrices!

8. Clean Python / NumPy Implementation

Below is the verified numerical implementation comparing the naive Normal Equation against the production QR factorization and NumPy's `np.linalg.lstsq`: 

import numpy as np

def least_squares_normal_eq(X: np.ndarray, y: np.ndarray) -> np.ndarray:
    """
    Closed-form least squares via Normal Equations.
    WARNING: Numerically sensitive if X is ill-conditioned.
    """
    XtX = X.T @ X
    Xty = X.T @ y
    # Solve XtX @ theta = Xty without explicit matrix inversion
    return np.linalg.solve(XtX, Xty)

def least_squares_qr(X: np.ndarray, y: np.ndarray) -> np.ndarray:
    """
    Numerically stable least squares via thin QR decomposition: X = Q R.
    R @ theta = Q.T @ y
    """
    Q, R = np.linalg.qr(X, mode='reduced')
    Qty = Q.T @ y
    # Back-substitution on upper triangular matrix R
    return np.linalg.solve(R, Qty)

# Verification Test with Example 1 Dataset
X_toy = np.array([[1.0, 1.0],
                  [2.0, 1.0],
                  [3.0, 1.0]])
y_toy = np.array([2.0, 2.0, 4.0])

theta_normal = least_squares_normal_eq(X_toy, y_toy)
theta_qr = least_squares_qr(X_toy, y_toy)
theta_numpy, residuals, rank, s = np.linalg.lstsq(X_toy, y_toy, rcond=None)

print(f"Normal Equations: theta = {theta_normal}")
print(f"QR Decomposition: theta = {theta_qr}")
print(f"NumPy lstsq:      theta = {theta_numpy}")

# Test Assertions
np.testing.assert_allclose(theta_normal, [1.0, 2.0/3.0], rtol=1e-5)
np.testing.assert_allclose(theta_qr, [1.0, 2.0/3.0], rtol=1e-5)
print("All mathematical assertions passed successfully!")

9. Computational Complexity & Efficiency

Method Time Complexity (Flops) Memory Footprint Conditioning Sensitivity Recommended Context
Normal Equations $O(m n^2 + rac{1}{3} n^3)$ $O(n^2)$ (stores $A^TA$) $\kappa(A)^2$ (Poor) Small $n \ll m$, dense streaming batches
QR Factorization $O(2 m n^2 - rac{2}{3} n^3)$ $O(m n)$ (stores $Q$) $\kappa(A)$ (Excellent) Standard dense regression default
SVD Decomposition $O(4 m n^2 + 8 n^3)$ $O(m n)$ $\kappa(A)$ (Gold Standard) Rank-deficient matrices ($ ext{rank} < n$)

10. Connection to Real Machine Learning

  • Ordinary Least Squares (OLS): The foundational linear supervised learning algorithm directly models $y = X w + \epsilon$.
  • Ridge Regression ($L_2$ Regularization): Solves ill-conditioning by adding $\lambda I$ to $A^T A$: $$\hat{x}_{ ext{ridge}} = (A^T A + \lambda I)^{-1} A^T b$$ Since $A^T A$ is positive semi-definite ($\lambda_i \ge 0$), $A^T A + \lambda I$ has strictly positive eigenvalues ($\lambda_i + \lambda > 0$), guaranteeing invertibility even when $n > m$!
  • Kernel Ridge Regression: Uses dual formulation via inner products to fit non-linear functions in infinite-dimensional Reproducing Kernel Hilbert Spaces (RKHS).

15. Summary & Formula Vault

High-Yield Formula Cheat Sheet
  • Rank-Nullity Theorem: $ ext{rank}(A) + ext{nullity}(A) = n$ (number of columns).
  • Orthogonal Complements: $C(A)^\perp = N(A^T)$ and $C(A^T)^\perp = N(A)$.
  • Rank-1 Projection Matrix: $P = rac{v v^T}{v^T v}$ (projects onto line spanned by $v$).
  • Subspace Projection Matrix: $P = A(A^T A)^{-1} A^T$.
  • Normal Equations: $A^T A \hat{x} = A^T b \implies \hat{x} = (A^T A)^{-1} A^T b$.
  • Orthogonality Principle: $A^T e = A^T (b - A\hat{x}) = 0 \iff e \perp C(A)$.
  • QR Factorization Solution: $R \hat{x} = Q^T b$.

16. Common Misconceptions Table

Misconception Mathematical Reality Why it Matters in ML
"If $Ax = b$ has no solution, we cannot use linear models." Least squares finds $\hat{x}$ minimizing Euclidean error $\|Ax - b\|_2^2$, providing the optimal approximation. Real datasets are noisy; exact interpolation overfits and usually does not exist.
"A projection matrix $P$ changes the vector length on every repeated multiplication." $P$ is idempotent: $P^2 = P$. Projecting an already-projected vector changes nothing ($P(Pb) = Pb$). Subspace projection operators stabilize in a single step.
"Computing $\hat{x} = (A^TA)^{-1} A^T b$ is how NumPy calculates regression." NumPy uses QR or SVD because forming $A^TA$ squares the condition number $\kappa(A)^2$, losing precision. Avoid `inv(X.T @ X)` in production pipelines; always use `np.linalg.lstsq` or QR.
