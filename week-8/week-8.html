Week 8: Unconstrained Optimization, Taylor Series & Gradient Descent

Detailed notes, algorithmic foundations, mathematical formulations, and Python implementations aligned with the IIT Madras lecture series.

1. Optimization as the Core Engine of Machine Learning

Machine learning training translates directly into mathematical optimization: finding parameter vector $w^* \in \mathbb{R}^d$ that minimizes an empirical loss function $f(w)$:

$$w^* = \arg\min_{w \in \mathbb{R}^d} f(w)$$

For unconstrained optimization, optimality is governed by calculus conditions:

  • First-Order Necessary Condition: $\nabla f(w^*) = 0$ (stationary point).
  • Second-Order Sufficient Condition: $\nabla f(w^*) = 0$ and Hessian matrix $\nabla^2 f(w^*) \succ 0$ (strictly positive definite $\implies$ local minimum).

2. Multivariate Taylor Expansion & Hessian Curvature

The second-order Taylor approximation of $f$ around point $w_0$ captures both slope and curvature:

$$f(w) \approx f(w_0) + \nabla f(w_0)^T (w - w_0) + \frac{1}{2} (w - w_0)^T \nabla^2 f(w_0) (w - w_0)$$

The eigenvalues of the symmetric Hessian matrix $\nabla^2 f(w_0)$ dictate the local geometry: if all eigenvalues are positive, the surface is convex bowl-shaped; if eigenvalues have mixed signs, $w_0$ is a saddle point.

3. The Gradient Descent Algorithm

Gradient Descent iteratively updates parameters along the negative gradient direction:

$$w_{t+1} = w_t - \eta_t \nabla f(w_t)$$

where $\eta_t > 0$ is the learning rate (step size). If $f$ is $L$-Lipschitz smooth ($\nabla^2 f(w) \preceq L I$), choosing $\eta \le 1/L$ guarantees monotonic decrease in objective value:

$$f(w_{t+1}) \le f(w_t) - \frac{\eta}{2} \|\nabla f(w_t)\|^2$$

4. Python Implementation: Gradient Descent with Convergence Tracking

import numpy as np

# Quadratic objective function: f(w) = 0.5 * w^T A w - b^T w
A = np.array([[3.0, 1.0], [1.0, 2.0]])
b = np.array([1.0, 2.0])

def loss(w):
    return 0.5 * w.T @ A @ w - b.T @ w

def grad(w):
    return A @ w - b

# Gradient Descent
w = np.array([10.0, -10.0])
lr = 0.2
trajectory = [w.copy()]

for step in range(50):
    g = grad(w)
    if np.linalg.norm(g) < 1e-6:
        break
    w -= lr * g
    trajectory.append(w.copy())

w_opt_analytical = np.linalg.solve(A, b)
print(f"Converged after {len(trajectory)} steps to: {w}")
print(f"Analytical Optimum A^-1 b: {w_opt_analytical}")
print("Final Residual Norm:", np.linalg.norm(w - w_opt_analytical))
