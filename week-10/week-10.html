Week 10: Duality, KKT Conditions & Optimization in ML

Detailed notes, algorithmic foundations, mathematical formulations, and Python implementations aligned with the IIT Madras lecture series.

1. Lagrangian Duality: Primal & Dual Problems

Consider the general standard non-linear program:

$$\min_{x} f_0(x) \quad \text{s.t.} \quad f_i(x) \le 0 \; (i=1,\dots,m), \quad h_j(x) = 0 \; (j=1,\dots,p)$$

The Lagrangian with dual multipliers $\lambda \ge 0$ and $\nu$ is:

$$\mathcal{L}(x, \lambda, \nu) = f_0(x) + \sum_{i=1}^m \lambda_i f_i(x) + \sum_{j=1}^p \nu_j h_j(x)$$

The Lagrange Dual Function is the infimum over primal variables:

$$g(\lambda, \nu) = \inf_{x} \mathcal{L}(x, \lambda, \nu)$$

Weak Duality: For any feasible primal $x$ and dual feasible $(\lambda \ge 0, \nu)$, $g(\lambda, \nu) \le f_0(x)$. Thus, the dual optimal value $d^*$ always lower-bounds the primal optimal value $p^*$: $d^* \le p^*$.

Strong Duality ($d^* = p^*$): Holds under Slater's constraint qualification condition for convex optimization problems.

2. The Karush-Kuhn-Tucker (KKT) Optimality Conditions

When strong duality holds, the primal optimal $x^*$ and dual optimal $(\lambda^*, \nu^*)$ must satisfy the celebrated KKT Conditions:

ConditionMathematical StatementInterpretation
1. Primal Feasibility$f_i(x^*) \le 0, \; h_j(x^*) = 0$Solution satisfies all original constraints.
2. Dual Feasibility$\lambda_i^* \ge 0$Multipliers for inequality constraints are non-negative.
3. Complementary Slackness$\lambda_i^* f_i(x^*) = 0, \; \forall i$Either constraint is active ($f_i(x^*)=0$) or multiplier is zero ($\lambda_i^* = 0$).
4. Stationarity$\nabla_x \mathcal{L}(x^*, \lambda^*, \nu^*) = 0$Gradient of Lagrangian vanishes at optimum.

3. Application to Support Vector Machines (SVM)

In hard-margin SVM, we maximize the geometric margin $\frac{2}{\|w\|_2}$ subject to correct classification $y_i(w^T x_i + b) \ge 1$:

$$\min_{w, b} \frac{1}{2}\|w\|_2^2 \quad \text{s.t.} \quad 1 - y_i(w^T x_i + b) \le 0$$

By complementary slackness $\alpha_i [1 - y_i(w^T x_i + b)] = 0$:

  • If point is strictly outside margin ($y_i(w^Tx_i+b) > 1$), then $\alpha_i = 0$.
  • If point lies on the margin ($y_i(w^Tx_i+b) = 1$), then $\alpha_i > 0$. These points are the Support Vectors!

4. Python Implementation: Simplified Linear SVM via Dual Formulation

import numpy as np

# Synthetic separable dataset
X = np.array([[1, 2], [2, 3], [3, 3], [6, 5], [7, 7], [8, 6]], dtype=float)
y = np.array([-1, -1, -1, 1, 1, 1], dtype=float)

# Subgradient descent for primal soft-margin SVM: min 0.5*||w||^2 + C * sum max(0, 1 - y_i(w^T x_i + b))
w = np.zeros(2)
b = 0.0
lr = 0.01
C = 10.0

for epoch in range(500):
    for i in range(len(X)):
        condition = y[i] * (np.dot(X[i], w) + b) >= 1
        if condition:
            w -= lr * (w / len(X))
        else:
            w -= lr * (w / len(X) - C * y[i] * X[i])
            b -= lr * (-C * y[i])

print("Learned SVM Weights w:", np.round(w, 3))
print("Learned SVM Bias b:", np.round(b, 3))
margin_scores = y * (X @ w + b)
print("Margin scores (>= 1 for correct margins):", np.round(margin_scores, 2))
