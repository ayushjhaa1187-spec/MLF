Linear Algebra & Matrix Geometry

Rank-Nullity Theorem
$$\text{rank}(A) + \text{nullity}(A) = n$$
Total number of columns equals dimensions of column space plus null space.
Projection Matrix (General)
$$P = A(A^T A)^{-1} A^T$$
Symmetric ($P^T = P$) and idempotent ($P^2 = P$). Eigenvalues are 0 and 1.
Normal Equations (Least Squares)
$$A^T A \hat{x} = A^T b \implies \hat{x} = (A^T A)^{-1} A^T b$$
Minimizes Euclidean residual $\|Ax - b\|_2^2$. Orthogonality: $A^T e = 0$.
Spectral Theorem
$$A = Q \Lambda Q^T = \sum_{i=1}^n \lambda_i q_i q_i^T$$
Real symmetric matrices have real eigenvalues and orthonormal eigenvectors.
Singular Value Decomposition (SVD)
$$A = U \Sigma V^T = \sum_{i=1}^r \sigma_i u_i v_i^T$$
Singular values $\sigma_i = \sqrt{\lambda_i(A^T A)}$. Eckart-Young optimal rank-$k$ approximation.
Principal Component Analysis (PCA)
$$\Sigma = \frac{1}{N} X^T X = Q \Lambda Q^T, \quad z_k = X q_k$$
Maximizes projected empirical variance; eigenvalues $\lambda_k$ equal variance on PC $k$.

Multivariate Calculus & Optimization

Multivariate Taylor Expansion
$$f(x) \approx f(x_0) + \nabla f(x_0)^T \Delta x + \frac{1}{2} \Delta x^T H \Delta x$$
Second-order local curvature quadratic approximation.
Gradient Descent Update
$$x^{(k+1)} = x^{(k)} - \eta \nabla f(x^{(k)})$$
Convergence guaranteed for $L$-smooth convex functions when $\eta < 2/L$.
KKT Optimality Conditions
$$\nabla \mathcal{L} = 0, \; \lambda_i \ge 0, \; \lambda_i g_i(x) = 0$$
Primal feasibility, dual feasibility, and complementary slackness for inequality constraints.

Probability & Statistical Models

Bayes' Theorem
$$P(A \mid B) = \frac{P(B \mid A) P(A)}{P(B)} = \frac{P(B \mid A) P(A)}{\sum_k P(B \mid A_k) P(A_k)}$$
Posterior equals likelihood times prior divided by marginal evidence.
Multivariate Normal Density
$$p(x) = \frac{1}{(2\pi)^{d/2} |\Sigma|^{1/2}} \exp\left( -\frac{1}{2} (x - \mu)^T \Sigma^{-1} (x - \mu) \right)$$
Quadratic Mahalanobis distance $(x - \mu)^T \Sigma^{-1} (x - \mu)$ defines elliptical contours.

Master Common Misconceptions Matrix

ConceptCommon FallacyMathematical Reality
Projection $P$ "Multiplying by $P$ twice reduces vector length further." $P$ is idempotent: $P^2 = P$. Once a vector is in $C(A)$, projecting it again changes nothing ($P(Pb) = Pb$).
Invertibility of $A^T A$ "$A^T A$ is always invertible for any matrix $A$." $A^T A$ is invertible if and only if $A$ has linearly independent columns ($\text{rank}(A) = n$).
Eigenvectors of $A$ vs $A^T A$ "The eigenvectors of $A$ and $A^T A$ are the same." $A$ and $A^T A$ have different eigenvectors in general. The eigenvectors of $A^T A$ are the right singular vectors $V$ of $A$.
Gradient Descent Step "Taking a larger learning rate always reaches the minimum faster." If $\eta > 2/L$, the updates overshoot and diverge towards infinity.
Independence vs Orthogonality "Uncorrelated random variables are always independent." Zero covariance ($\text{Cov}(X, Y) = 0$) implies independence only if the joint distribution is jointly Gaussian.
