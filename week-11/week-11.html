Week 11: Probability Foundations: Discrete & Continuous Distributions

Detailed notes, algorithmic foundations, mathematical formulations, and Python implementations aligned with the IIT Madras lecture series.

1. Probability Spaces, Conditioning & Bayes' Rule

A rigorous probability model is formalized as a triplet $(\Omega, \mathcal{F}, P)$:

  • $\Omega$: Sample space (set of all possible outcomes).
  • $\mathcal{F}$: $\sigma$-algebra of observable events.
  • $P$: Probability measure satisfying Kolmogorov's axioms: $P(A) \ge 0$, $P(\Omega) = 1$, and countable additivity.
Bayes' Theorem

Given evidence $B$ with $P(B) > 0$, the posterior probability of hypothesis $A$ is: $$P(A|B) = \frac{P(B|A) P(A)}{P(B)} = \frac{P(B|A) P(A)}{\sum_{i} P(B|A_i) P(A_i)}$$

2. Discrete Random Variables & Key Distributions

A random variable $X: \Omega \to \mathbb{R}$ maps experimental outcomes to real numbers.

3. Continuous Random Variables & PDFs

For a continuous random variable $X$, probabilities are computed via an integral over the Probability Density Function (PDF) $f_X(x)$:

$$P(a \le X \le b) = \int_a^b f_X(x) \, dx, \quad \int_{-\infty}^\infty f_X(x) \, dx = 1$$

Gaussian (Normal) Distribution $\mathcal{N}(\mu, \sigma^2)$:

$$f_X(x) = \frac{1}{\sqrt{2\pi \sigma^2}} \exp\left( -\frac{(x - \mu)^2}{2\sigma^2} \right)$$

4. Python Implementation: Probability Distributions & Expectations

import numpy as np

# 1. Empirical Verification of Linearity of Expectation: E[X + Y] = E[X] + E[Y]
N = 100000
X = np.random.binomial(n=10, p=0.3, size=N)
Y = np.random.poisson(lam=4.0, size=N)

print("Empirical E[X]:", np.mean(X), "(Theoretical: 3.0)")
print("Empirical E[Y]:", np.mean(Y), "(Theoretical: 4.0)")
print("Empirical E[X + Y]:", np.mean(X + Y), "(Theoretical: 7.0)")

# 2. Continuous Gaussian sampling and empirical moments
mu, sigma = 5.0, 2.0
samples = np.random.normal(loc=mu, scale=sigma, size=N)
print(f"Sample Mean: {np.mean(samples):.3f}, Sample Variance: {np.var(samples):.3f}")
