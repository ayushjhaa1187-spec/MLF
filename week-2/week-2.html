Week 2: Calculus for ML: Sets, Functions & Derivatives

Detailed notes, algorithmic foundations, mathematical formulations, and Python implementations aligned with the IIT Madras lecture series.

1. Sets, Mappings & Functions in Vector Spaces

Vector calculus forms the analytical foundation for machine learning optimization. A function $f: \mathbb{R}^d \to \mathbb{R}$ maps a $d$-dimensional feature vector $x = [x_1, x_2, \dots, x_d]^T$ to a scalar value (such as loss or probability).

Formal Definition: Continuity

A function $f: \mathbb{R}^d \to \mathbb{R}$ is continuous at $x_0$ if for every $\epsilon > 0$, there exists $\delta > 0$ such that: $$\|x - x_0\| < \delta \implies |f(x) - f(x_0)| < \epsilon$$

2. Univariate & Multivariate Derivatives

The derivative quantifies the instantaneous rate of change of a function. In higher dimensions, the Gradient Vector $\nabla f(x)$ aggregates all partial derivatives:

$$\nabla f(x) = \begin{bmatrix} \frac{\partial f}{\partial x_1} \\ \frac{\partial f}{\partial x_2} \\ \vdots \\ \frac{\partial f}{\partial x_d} \end{bmatrix} \in \mathbb{R}^d$$

Directional Derivative: The rate of change of $f$ in the direction of a unit vector $v$ ($||v|| = 1$) is given by the inner product:

$$D_v f(x) = \nabla f(x)^T v = \|\nabla f(x)\| \cos(\theta)$$

This directly proves that the directional derivative is maximized when $\theta = 0$, meaning the gradient points in the direction of steepest ascent, and $-\nabla f(x)$ points in the direction of steepest descent.

3. Linear Approximations & Tangent Hyperplanes

The first-order Taylor approximation of $f$ near $x_0$ defines the tangent hyperplane:

$$f(x) \approx f(x_0) + \nabla f(x_0)^T (x - x_0)$$

This affine approximation replaces complex non-linear functions with a local linear model, which is the foundational principle underlying gradient descent update rules.

4. Python Implementation: Numerical & Symbolic Gradients

Computing numerical gradients via finite differences:

import numpy as np

def numerical_gradient(f, x, h=1e-5):
    grad = np.zeros_like(x, dtype=float)
    for i in range(len(x)):
        x_forward = np.array(x, dtype=float)
        x_backward = np.array(x, dtype=float)
        x_forward[i] += h
        x_backward[i] -= h
        grad[i] = (f(x_forward) - f(x_backward)) / (2 * h)
    return grad

# Example: Rosenbrock-style function f(x, y) = x^2 + 10*y^2
def func(v):
    return v[0]**2 + 10 * v[1]**2

x0 = np.array([3.0, 2.0])
print("Analytical Gradient [2x, 20y]:", np.array([2*x0[0], 20*x0[1]]))
print("Numerical Gradient:", numerical_gradient(func, x0))
