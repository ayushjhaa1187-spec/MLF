Week 5: Complex Matrices, Hermitian Matrices & Spectral Theory

Detailed notes, algorithmic foundations, mathematical formulations, and Python implementations aligned with the IIT Madras lecture series.

1. Complex Vector Spaces & Hermitian Matrices

In complex vector spaces $\mathbb{C}^n$, the inner product is defined as $\langle x, y \rangle = x^* y = \sum \bar{x}_i y_i$, where $x^*$ is the conjugate transpose (Hermitian transpose).

A matrix $A \in \mathbb{C}^{n \times n}$ is Hermitian if $A = A^*$. If $A$ is real, this reduces to a real symmetric matrix ($A = A^T$).

Fundamental Theorem: Real Eigenvalues

Theorem: Every eigenvalue of a Hermitian matrix is strictly real.

Proof: Let $Av = \lambda v$ with $v \neq 0$. Take the conjugate transpose: $v^* A^* = \bar{\lambda} v^*$. Multiply both sides: $$v^* A v = v^* (\lambda v) = \lambda v^* v$$ $$(v^* A^*) v = (\bar{\lambda} v^*) v = \bar{\lambda} v^* v$$ Since $A = A^*$, $v^* A v = v^* A^* v \implies \lambda \|v\|^2 = \bar{\lambda} \|v\|^2$. Since $\|v\| \neq 0$, $\lambda = \bar{\lambda}$, which holds if and only if $\lambda \in \mathbb{R}$.

2. Unitary Matrices & Spectral Theorem

A complex matrix $U$ is Unitary if $U^* U = U U^* = I$. Unitary matrices preserve inner products and lengths: $\|Ux\| = \|x\|$.

The Spectral Theorem for Hermitian Matrices: Any Hermitian matrix $A$ can be unitarily diagonalized by an orthonormal basis of eigenvectors:

$$A = U \Lambda U^* = \sum_{i=1}^n \lambda_i u_i u_i^*$$

Each $u_i u_i^*$ is a rank-1 projection operator onto the eigenspace spanned by $u_i$.

3. The Rayleigh Quotient

For a Hermitian matrix $A$, the Rayleigh Quotient is defined for $x \neq 0$ as:

$$R_A(x) = \frac{x^* A x}{x^* x}$$

The Courant-Fischer theorem guarantees that the minimum and maximum of $R_A(x)$ correspond directly to the smallest and largest eigenvalues:

$$\lambda_{\min} \le R_A(x) \le \lambda_{\max}$$

4. Python Implementation: Spectral Decomposition

import numpy as np

# Create a complex Hermitian matrix
A = np.array([
    [2.0 + 0.0j, 1.0 - 1.0j],
    [1.0 + 1.0j, 3.0 + 0.0j]
])

# Verify A == A^*
assert np.allclose(A, A.conj().T), "Matrix must be Hermitian"

# Compute eigenvalues and eigenvectors
eigvals, U = np.linalg.eigh(A)
print("Eigenvalues (all strictly real):", eigvals)
print("Unitary eigenvectors U:\n", np.round(U, 3))

# Check U^* U == I
print("Is U Unitary?", np.allclose(U.conj().T @ U, np.eye(2)))

# Spectral reconstruction
A_rec = U @ np.diag(eigvals) @ U.conj().T
print("Reconstructed A matches original:", np.allclose(A, A_rec))
