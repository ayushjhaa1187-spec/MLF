## 1. Classification Taxonomy

To ensure mathematical accuracy, transparency, and pedagogical rigor, all content elements are classified into four explicit verification tiers:

- **Present and Verified (`PV`):** Content exists, mathematical derivations have been verified for accuracy, code runs without errors, video mapping matches the authentic lecture, and external links resolve correctly.
- **Present but Incomplete (`PI`):** Content exists and is accurate in what it states, but lacks necessary depth (e.g. missing numerical step-by-step arithmetic, missing edge cases, or missing interactive visual labs).
- **Present but Unverified (`PU`):** Content exists, but provenance or authenticity has not been conclusively traced back to official course materials (e.g., questions labeled "IITM Exam" without specific term/assignment citation).
- **Missing (`M`):** Content required by the comprehensive 18-point rubric or syllabus standard does not exist yet.
