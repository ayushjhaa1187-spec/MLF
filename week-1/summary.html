Week 1: High-Yield Summary

Introduction to Machine Learning, Tasks & Taxonomy • Core Formulas, Definitions & Quick Code

Core Taxonomy
Supervised (Labeled targets: Regression continuous, Classification discrete), Unsupervised (Unlabeled: Dimensionality reduction, Density estimation, Clustering).
Empirical Risk Minimization
We approximate theoretical risk $R(f) = \mathbb{E}[L(f(x), y)]$ using empirical average $\hat{R}(f) = \frac{1}{N}\sum_{i=1}^N L(f(x_i), y_i)$.
Generalization vs Memorization
A model must minimize error on unseen test data from the same distribution, preventing overfitting to training noise.
