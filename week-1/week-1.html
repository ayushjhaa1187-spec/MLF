Week 1: Introduction to Machine Learning, Tasks & Taxonomy

Detailed notes, algorithmic foundations, mathematical formulations, and Python implementations aligned with the IIT Madras lecture series.

1. What is Machine Learning? Data & Models

Machine Learning is the study of computer algorithms that improve automatically through experience. Unlike traditional programming where human engineers hardcode rules, a machine learning system synthesizes rules by finding patterns in observational data.

The Fundamental Paradigm Shift

Traditional Software: Input Data + Explicit Rules $\longrightarrow$ Output Answers.

Machine Learning: Input Data + Desired Outputs $\longrightarrow$ Learned Hypothesis Function (Rules/Model).

Formally, given an input space $\mathcal{X} \subseteq \mathbb{R}^d$ and an output space $\mathcal{Y}$, our goal is to find a hypothesis function $f: \mathcal{X} \to \mathcal{Y}$ from a hypothesis class $\mathcal{H}$ that minimizes the expected risk:

$$R(f) = \mathbb{E}_{(x, y) \sim \mathcal{D}}[L(f(x), y)]$$

where $L: \mathcal{Y} \times \mathcal{Y} \to \mathbb{R}_+$ is a task-specific loss function, and $\mathcal{D}$ is the underlying joint data distribution.

2. Supervised Learning: Regression vs Classification

In Supervised Learning, the training dataset consists of input-output pairs $\mathcal{D}_{train} = \{(x_1, y_1), (x_2, y_2), \dots, (x_N, y_N)\}$.

  • Regression: The target $y_i \in \mathbb{R}$ is continuous (e.g., house prices, temperature, stock yield). Standard loss is Mean Squared Error: $$L_{MSE}(f(x), y) = \frac{1}{2}(f(x) - y)^2$$
  • Classification: The target $y_i \in \{1, 2, \dots, C\}$ is discrete (e.g., spam vs non-spam, disease diagnosis). Standard loss is Cross-Entropy: $$L_{CE}(\hat{y}, y) = -\sum_{c=1}^C \mathbf{1}(y = c) \log \hat{y}_c$$
Empirical Risk Minimization (ERM)

Since the true distribution $\mathcal{D}$ is unknown, we approximate the true risk by minimizing the empirical risk over the training set: $$\hat{R}_{emp}(f) = \frac{1}{N} \sum_{i=1}^N L(f(x_i), y_i)$$

3. Unsupervised Learning: Dimensionality Reduction & Density Estimation

In Unsupervised Learning, we observe only inputs $\mathcal{D} = \{x_1, x_2, \dots, x_N\}$ without any supervisory labels.

Dimensionality Reduction

Project high-dimensional data $x \in \mathbb{R}^D$ into a lower-dimensional space $z \in \mathbb{R}^d$ ($d \ll D$) while preserving intrinsic variance or geometric distances (e.g., PCA, t-SNE, Autoencoders).

Density Estimation

Model the underlying probability density function $p(x)$ that generated the observations (e.g., Gaussian Mixture Models, Kernel Density Estimation) to identify anomalies or generate new samples.

4. Python Implementation: Dataset Generation & Baseline Predictor

Let's implement a foundational data synthesis and k-Nearest Neighbors classifier from scratch using NumPy:

import numpy as np

# 1. Generate synthetic 2-class dataset
np.random.seed(42)
N = 100
X_class0 = np.random.randn(N, 2) + np.array([-2, -2])
X_class1 = np.random.randn(N, 2) + np.array([2, 2])
X = np.vstack([X_class0, X_class1])
y = np.array([0]*N + [1]*N)

# 2. k-NN Classifier from scratch
class KNNClassifier:
    def __init__(self, k=3):
        self.k = k

    def fit(self, X_train, y_train):
        self.X_train = X_train
        self.y_train = y_train

    def predict(self, X_test):
        preds = []
        for x in X_test:
            # Compute Euclidean distances to all training points
            distances = np.linalg.norm(self.X_train - x, axis=1)
            # Find indices of k smallest distances
            k_indices = np.argsort(distances)[:self.k]
            k_nearest_labels = self.y_train[k_indices]
            # Majority vote
            majority = np.bincount(k_nearest_labels).argmax()
            preds.append(majority)
        return np.array(preds)

knn = KNNClassifier(k=5)
knn.fit(X, y)
test_points = np.array([[-1.5, -1.8], [1.8, 2.1]])
print("Predictions for test points:", knn.predict(test_points))
# Output: [0, 1]
