Week 7: Principal Component Analysis (PCA) & Dimensionality Reduction

Dimensionality reduction from first principles: the maximum variance formulation, Lagrangian derivations, Pythagorean error equivalence, SVD correspondence, and high-dimensional computational shortcuts.

1. Motivation, Prerequisites & The Centering Imperative

In high-dimensional machine learning, raw feature spaces contain redundancy, multicollinearity, and excessive noise. Principal Component Analysis (PCA) is the foundational linear unsupervised dimensionality reduction technique: it finds an orthogonal basis of directions that capture maximal variance.

Why Mean-Centering is Mandatory

Let observation vectors $x_1, \dots, x_N \in \mathbb{R}^D$ have sample mean $\mu = \frac{1}{N}\sum_{i=1}^N x_i$. The true variance along direction unit vector $u$ is:

$$\text{Var}(u^T x) = \frac{1}{N} \sum_{i=1}^N (u^T (x_i - \mu))^2 = u^T \left[ \frac{1}{N}\sum_{i=1}^N (x_i - \mu)(x_i - \mu)^T \right] u = u^T \Sigma u$$

If data is not centered, the quantity $\frac{1}{N}\sum (u^T x_i)^2 = \text{Var}(u^T x) + (u^T \mu)^2$ maximizes the second raw moment. If $\mu$ is far from the origin, $u_1$ will simply point toward the centroid $\mu$, capturing no meaningful variance within the data cloud! Centering ($x_c = x - \mu$) ensures that the coordinate origin sits exactly at the center of mass.

2. Mathematical Derivations: Maximum Variance & Error Minimization

Lagrangian Derivation of the First Principal Component

Let centered data $X_c \in \mathbb{R}^{N \times D}$ have sample covariance matrix $\Sigma = \frac{1}{N} X_c^T X_c \in \mathbb{R}^{D \times D}$.

We seek a unit vector $u_1 \in \mathbb{R}^D$ ($\|u_1\|_2 = 1$) maximizing the projected variance:

$$\max_{u_1} u_1^T \Sigma u_1 \quad \text{subject to} \quad u_1^T u_1 = 1$$

Introduce the Lagrange multiplier $\lambda_1$:

$$\mathcal{L}(u_1, \lambda_1) = u_1^T \Sigma u_1 - \lambda_1 (u_1^T u_1 - 1)$$

Taking the vector derivative with respect to $u_1$ (using $\nabla_u (u^T \Sigma u) = 2 \Sigma u$ for symmetric $\Sigma$):

$$\nabla_{u_1} \mathcal{L} = 2 \Sigma u_1 - 2 \lambda_1 u_1 = 0 \implies \Sigma u_1 = \lambda_1 u_1$$

This is the classic eigenvalue equation! Left-multiplying by $u_1^T$:

$$u_1^T \Sigma u_1 = \lambda_1 (u_1^T u_1) = \lambda_1$$

Therefore, the projected variance equals the eigenvalue $\lambda_1$. To maximize variance, $u_1$ must be the eigenvector corresponding to the largest eigenvalue $\lambda_1 = \lambda_{\max}(\Sigma)$.

Pythagorean Equivalence: Max Variance $\iff$ Min Reconstruction Error

For any orthogonal projection matrix $P = u u^T$, any centered point $x$ decomposes into projected and residual components:

$$x = P x + (I - P)x, \quad \text{where } (P x) \perp ((I - P)x)$$

By the Pythagorean theorem:

$$\|x\|_2^2 = \|P x\|_2^2 + \|x - P x\|_2^2$$

Averaging across all $N$ data points:

$$\frac{1}{N}\sum_{i=1}^N \|x_i\|^2 = \frac{1}{N}\sum_{i=1}^N \|P x_i\|^2 + \frac{1}{N}\sum_{i=1}^N \|x_i - P x_i\|^2$$ $$\text{Total Variance } \text{Tr}(\Sigma) = \text{Projected Variance } V(u) + \text{Reconstruction MSE } E(u)$$

Because $\text{Tr}(\Sigma)$ is an invariant property of the original dataset, maximizing projected variance $V(u)$ is mathematically identical to minimizing reconstruction error $E(u)$!

4. Worked Numerical Walkthrough 1: Hand-Computable 2D Dataset (Rank 1)

Consider three 2D data points: $x_1 = (-2, -1)$, $x_2 = (0, 0)$, $x_3 = (2, 1)$.

Step 1: Verify Mean Centering $$\bar{x} = \frac{-2 + 0 + 2}{3} = 0, \quad \bar{y} = \frac{-1 + 0 + 1}{3} = 0 \implies \text{Data is strictly centered.}$$
Step 2: Compute Sample Covariance Matrix $\Sigma$ $$\Sigma = \frac{1}{3} \sum_{i=1}^3 x_i x_i^T = \frac{1}{3} \left[ \begin{bmatrix} 4 & 2 \\ 2 & 1 \end{bmatrix} + \begin{bmatrix} 0 & 0 \\ 0 & 0 \end{bmatrix} + \begin{bmatrix} 4 & 2 \\ 2 & 1 \end{bmatrix} \right] = \frac{1}{3} \begin{bmatrix} 8 & 4 \\ 4 & 2 \end{bmatrix} = \begin{bmatrix} 8/3 & 4/3 \\ 4/3 & 2/3 \end{bmatrix}$$
Step 3: Characteristic Equation & Eigenvalues $$\det(\Sigma - \lambda I) = \left(\frac{8}{3} - \lambda\right)\left(\frac{2}{3} - \lambda\right) - \left(\frac{4}{3}\right)^2 = \lambda^2 - \frac{10}{3}\lambda + \frac{16}{9} - \frac{16}{9} = \lambda\left(\lambda - \frac{10}{3}\right) = 0$$ $$\lambda_1 = \frac{10}{3} \approx 3.333, \quad \lambda_2 = 0$$

Total variance: $\text{Tr}(\Sigma) = \frac{8}{3} + \frac{2}{3} = \frac{10}{3}$. PC1 captures $\frac{10/3}{10/3} = 100\%$ of total variance!

Step 4: Principal Direction $u_1$ & Projected Scores $$\left(\Sigma - \frac{10}{3}I\right)u_1 = \begin{bmatrix} -2/3 & 4/3 \\ 4/3 & -8/3 \end{bmatrix} \begin{bmatrix} u_{11} \\ u_{12} \end{bmatrix} = 0 \implies u_{11} = 2 u_{12} \implies u_1 = \frac{1}{\sqrt{5}}\begin{bmatrix} 2 \\ 1 \end{bmatrix}$$

Projected coordinates $z_i = u_1^T x_i$:

$$z_1 = \frac{1}{\sqrt{5}}(2(-2) + 1(-1)) = -\frac{5}{\sqrt{5}} = -\sqrt{5} \approx -2.236$$ $$z_2 = 0, \quad z_3 = \frac{1}{\sqrt{5}}(2(2) + 1(1)) = \sqrt{5} \approx 2.236$$

Sample variance of projected scores: $\frac{1}{3}((-\sqrt{5})^2 + 0^2 + (\sqrt{5})^2) = \frac{1}{3}(5 + 0 + 5) = \frac{10}{3} = \lambda_1$. Exactly matches theory!

5. Worked Numerical Walkthrough 2: 4-Point Dataset with Non-Zero Residual Variance

Consider four 2D points: $x_1 = (-1, -2)$, $x_2 = (-1, 0)$, $x_3 = (1, 0)$, $x_4 = (1, 2)$ (Mean is $[0, 0]$).

Step 1: Compute Covariance Matrix $$\Sigma = \frac{1}{4} \left[ \begin{bmatrix} 1 & 2 \\ 2 & 4 \end{bmatrix} + \begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix} + \begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix} + \begin{bmatrix} 1 & 2 \\ 2 & 4 \end{bmatrix} \right] = \frac{1}{4} \begin{bmatrix} 4 & 4 \\ 4 & 8 \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 2 \end{bmatrix}$$
Step 2: Eigenvalues & Explained Variance $$\det(\Sigma - \lambda I) = (1 - \lambda)(2 - \lambda) - 1 = \lambda^2 - 3\lambda + 1 = 0$$ $$\lambda_1 = \frac{3 + \sqrt{5}}{2} \approx 2.618, \quad \lambda_2 = \frac{3 - \sqrt{5}}{2} \approx 0.382$$

Total variance: $\text{Tr}(\Sigma) = 1 + 2 = 3.000$.

Explained Variance Ratio of PC1: $\frac{2.618}{3.000} \approx 87.27\%$.

Residual Reconstruction Error: $\lambda_2 \approx 0.382$ ($12.73\%$).

6. Exact Equivalence: PCA via SVD

In practical machine learning libraries (such as scikit-learn), PCA is almost never solved via eigendecomposition of $\Sigma$ (which requires $O(D^2)$ memory and computing $X^T X$); instead, it is solved directly via the Singular Value Decomposition of centered data $X_c$:

$$X_c = U \Sigma_{\text{svd}} V^T$$ $$\Sigma = \frac{1}{N} X_c^T X_c = \frac{1}{N} (V \Sigma_{\text{svd}} U^T)(U \Sigma_{\text{svd}} V^T) = V \left(\frac{\Sigma_{\text{svd}}^2}{N}\right) V^T$$
  • The right singular vectors (columns of $V$) are the exact principal loading vectors $u_i$.
  • The covariance eigenvalues relate to singular values by $\lambda_i = \frac{\sigma_i^2}{N}$.
  • The projected principal scores are $Z = X_c V = U \Sigma_{\text{svd}}$.
High-Dimensional Gram Matrix Shortcut ($N \ll D$)

When dealing with genetic arrays or facial images where feature count $D = 100,000$ vastly exceeds sample size $N = 50$, computing $X_c^T X_c$ ($100,000 \times 100,000$) is prohibitive. Instead, diagonalize the small $N \times N$ Gram matrix $K = X_c X_c^T$ ($50 \times 50$). If $K v = \mu v$, then multiplying by $X_c^T$ gives $(X_c^T X_c)(X_c^T v) = \mu (X_c^T v)$, proving that $X_c^T v$ is an exact eigenvector of the huge covariance matrix!

7. Python & NumPy Implementation with Mathematical Assertions

import numpy as np

class PCAFromScratch:
    def __init__(self, n_components=1):
        self.n_components = n_components
        self.components_ = None
        self.mean_ = None
        self.explained_variance_ = None
        self.explained_variance_ratio_ = None

    def fit(self, X):
        self.mean_ = np.mean(X, axis=0)
        X_c = X - self.mean_
        N = len(X)
        
        # Sample covariance matrix
        cov = (X_c.T @ X_c) / N
        eigvals, eigvecs = np.linalg.eigh(cov)
        
        # Sort descending
        idx = np.argsort(eigvals)[::-1]
        self.explained_variance_ = eigvals[idx]
        self.explained_variance_ratio_ = self.explained_variance_ / np.sum(eigvals)
        self.components_ = eigvecs[:, idx[:self.n_components]]
        return self

    def transform(self, X):
        return (X - self.mean_) @ self.components_

# Walkthrough 1 Assertion Check
X1 = np.array([[-2.0, -1.0], [0.0, 0.0], [2.0, 1.0]])
pca1 = PCAFromScratch(n_components=1).fit(X1)
assert np.isclose(pca1.explained_variance_[0], 10.0 / 3.0)
assert np.isclose(pca1.explained_variance_[1], 0.0)
assert np.isclose(pca1.explained_variance_ratio_[0], 1.0) # 100% variance

# Walkthrough 2 Assertion Check
X2 = np.array([[-1.0, -2.0], [-1.0, 0.0], [1.0, 0.0], [1.0, 2.0]])
pca2 = PCAFromScratch(n_components=1).fit(X2)
l1_expected = (3.0 + np.sqrt(5.0)) / 2.0
l2_expected = (3.0 - np.sqrt(5.0)) / 2.0
assert np.isclose(pca2.explained_variance_[0], l1_expected)
assert np.isclose(pca2.explained_variance_[1], l2_expected)
assert np.isclose(pca2.explained_variance_ratio_[0], l1_expected / 3.0)
