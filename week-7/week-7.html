Week 7: Principal Component Analysis (PCA) & Dimensionality Reduction

Detailed notes, algorithmic foundations, mathematical formulations, and Python implementations aligned with the IIT Madras lecture series.

1. Principal Component Analysis (PCA) Motivation

High-dimensional data frequently suffers from multicollinearity, redundant attributes, and the curse of dimensionality. PCA is an unsupervised linear dimensionality reduction technique that transforms $D$-dimensional correlated features into $d$ ($d \ll D$) uncorrelated coordinates called Principal Components.

2. Formulation: Maximizing Projected Variance

Let data matrix $X \in \mathbb{R}^{N \times D}$ be zero-centered (sample mean $\mu = 0$). The sample covariance matrix is:

$$\Sigma = \frac{1}{N} X^T X \in \mathbb{R}^{D \times D}$$

We seek a unit projection vector $u_1$ ($\|u_1\|_2 = 1$) such that the variance of the projected data $z_1 = X u_1$ is maximized:

$$\max_{u_1} \text{Var}(z_1) = \max_{u_1} \frac{1}{N} (X u_1)^T (X u_1) = \max_{u_1} u_1^T \Sigma u_1 \quad \text{s.t.} \quad u_1^T u_1 = 1$$

Setting up the Lagrangian: $\mathcal{L}(u_1, \lambda) = u_1^T \Sigma u_1 - \lambda (u_1^T u_1 - 1)$.

$$\nabla_{u_1} \mathcal{L} = 2 \Sigma u_1 - 2 \lambda u_1 = 0 \implies \Sigma u_1 = \lambda u_1$$

The optimal direction $u_1$ is precisely the eigenvector of $\Sigma$ corresponding to the largest eigenvalue $\lambda_1$! The maximum variance achieved is $u_1^T \Sigma u_1 = u_1^T (\lambda_1 u_1) = \lambda_1$.

3. Explained Variance Ratio & Scree Plot

The total variance in the dataset equals the trace of the covariance matrix: $\text{Tr}(\Sigma) = \sum_{i=1}^D \lambda_i$. The fraction of variance explained by the first $k$ components is:

$$\text{Explained Variance Ratio}(k) = \frac{\sum_{i=1}^k \lambda_i}{\sum_{j=1}^D \lambda_j}$$

4. Python Implementation: PCA from Scratch with NumPy

import numpy as np

class PCAFromScratch:
    def __init__(self, n_components=2):
        self.n_components = n_components
        self.components_ = None
        self.mean_ = None
        self.explained_variance_ratio_ = None

    def fit(self, X):
        # 1. Center the data
        self.mean_ = np.mean(X, axis=0)
        X_centered = X - self.mean_

        # 2. Compute sample covariance matrix
        cov = (X_centered.T @ X_centered) / len(X)

        # 3. Eigendecomposition
        eigvals, eigvecs = np.linalg.eigh(cov)

        # 4. Sort eigenvalues in descending order
        idx = np.argsort(eigvals)[::-1]
        eigvals = eigvals[idx]
        eigvecs = eigvecs[:, idx]

        # 5. Store top components and variance ratios
        self.components_ = eigvecs[:, :self.n_components]
        self.explained_variance_ratio_ = eigvals[:self.n_components] / np.sum(eigvals)
        return self

    def transform(self, X):
        X_centered = X - self.mean_
        return X_centered @ self.components_

# Demonstration on correlated synthetic data
np.random.seed(42)
X_synth = np.random.multivariate_normal(mean=[2, 5], cov=[[3.0, 2.5], [2.5, 3.0]], size=200)

pca = PCAFromScratch(n_components=1)
pca.fit(X_synth)
X_proj = pca.transform(X_synth)

print("Principal Component Direction:\n", pca.components_)
print("Explained Variance Ratio:", pca.explained_variance_ratio_)
