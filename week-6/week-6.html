Week 6: Singular Value Decomposition (SVD) & Positive Definiteness

Detailed notes, algorithmic foundations, mathematical formulations, and Python implementations aligned with the IIT Madras lecture series.

1. Singular Value Decomposition (SVD)

While eigendecomposition applies only to square diagonalizable matrices, the Singular Value Decomposition (SVD) applies to any matrix $A \in \mathbb{R}^{m \times n}$:

$$A = U \Sigma V^T$$
  • $U \in \mathbb{R}^{m \times m}$: Orthonormal matrix of left singular vectors (eigenvectors of $A A^T$).
  • $\Sigma \in \mathbb{R}^{m \times n}$: Diagonal matrix of non-negative singular values $\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_r > 0$.
  • $V \in \mathbb{R}^{n \times n}$: Orthonormal matrix of right singular vectors (eigenvectors of $A^T A$).

The singular values $\sigma_i$ are related to the eigenvalues of $A^T A$ by $\sigma_i = \sqrt{\lambda_i(A^T A)}$.

2. Geometric Interpretation & Action of SVD

Geometrically, any linear transformation $x \mapsto Ax$ factorizes into three simple sequential actions:

  1. $V^T$: An orthonormal rotation/reflection in the input space $\mathbb{R}^n$.
  2. $\Sigma$: A coordinate axis stretch by factors $\sigma_1, \sigma_2, \dots$.
  3. $U$: An orthonormal rotation/reflection in the output space $\mathbb{R}^m$.
Sphere to Ellipsoid

The SVD maps the unit sphere in $\mathbb{R}^n$ ($\{x : \|x\| = 1\}$) into a hyperellipsoid in $\mathbb{R}^m$, whose principal semi-axes have lengths $\sigma_i$ along directional vectors $u_i$.

3. Positive Definite Matrices & Quadratic Forms

A symmetric matrix $A \in \mathbb{R}^{n \times n}$ is Positive Definite ($A \succ 0$) if the quadratic form is strictly positive for all non-zero $x$:

$$x^T A x > 0, \quad \forall x \neq 0$$

Equivalent Characterizations:

  • All eigenvalues are strictly positive: $\lambda_i > 0$.
  • All leading principal minors are positive (Sylvester's criterion).
  • Has a unique Cholesky factorization: $A = L L^T$ with lower-triangular $L$.

4. Low-Rank Approximation (Eckart-Young-Mirsky)

By expressing $A$ as a sum of rank-1 outer products:

$$A = \sum_{i=1}^r \sigma_i u_i v_i^T$$

The best rank-$k$ approximation ($k < r$) in Frobenius norm is obtained by keeping only the top $k$ components:

$$A_k = \sum_{i=1}^k \sigma_i u_i v_i^T, \quad \min_{\text{rank}(B)=k} \|A - B\|_F = \sqrt{\sum_{i=k+1}^r \sigma_i^2}$$

5. Python Implementation: SVD & Low-Rank Compression

import numpy as np

# Create a sample synthetic 2D image matrix
np.random.seed(0)
A = np.random.randn(50, 40)

# Full SVD decomposition
U, S, Vt = np.linalg.svd(A, full_matrices=False)
print("Shapes -> U:", U.shape, "S:", S.shape, "Vt:", Vt.shape)

# Truncated rank-k approximation
def low_rank_approx(U, S, Vt, k):
    return (U[:, :k] * S[:k]) @ Vt[:k, :]

A_k5 = low_rank_approx(U, S, Vt, k=5)
frobenius_error = np.linalg.norm(A - A_k5, 'fro')
theoretical_error = np.sqrt(np.sum(S[5:]**2))

print(f"Empirical Frobenius Error (k=5): {frobenius_error:.4f}")
print(f"Theoretical Error sqrt(sum(S[k:]^2)): {theoretical_error:.4f}")
assert np.isclose(frobenius_error, theoretical_error)
